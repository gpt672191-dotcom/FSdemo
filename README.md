# FitStart AI

เว็บเริ่มต้นออกกำลังกายด้วย AI สำหรับมือใหม่ (ไทย / อังกฤษ)
ออนไลน์: https://gpt672191-dotcom.github.io/FSdemo/ · ติดตั้งเป็นแอปบนมือถือได้ (เมนูเบราว์เซอร์ → เพิ่มลงในหน้าจอหลัก)

## หน้าเว็บ

| ไฟล์ | หน้า | มีอะไร |
|---|---|---|
| `index.html` | หน้าแรก | แนะนำเว็บ, การ์ดเลือกหมวด, แถบทักทายบอก "วันนี้" ต้องฝึกอะไร / วันพัก, คำแนะนำปรับระดับจากความรู้สึกหลังฝึก |
| `for-you.html` | แนะนำ | คำแนะนำจาก น้ำหนัก/ส่วนสูง/อายุ: เป้าหมาย, แคลอรี่, โปรตีน, แผน, ท่า + ตัวนับดื่มน้ำ + ตัวนับโปรตีนจากอาหารไทย |
| `profile.html` | ข้อมูลส่วนตัว | ดู/แก้ไขข้อมูล, ความคืบหน้า (วันต่อเนื่อง ปฏิทิน 12 สัปดาห์ กราฟน้ำหนัก), เหรียญรางวัล 9 เหรียญ |
| `settings.html` | ตั้งค่า | ธีมสว่าง/มืด, ภาษา, ลดภาพเคลื่อนไหว, เปลี่ยนรหัสผ่าน, ดาวน์โหลด/ลบข้อมูล, ลบบัญชี |
| `admin.html` | ผู้ดูแลระบบ | สถิติการใช้งาน, จัดการผู้ใช้ (ระงับ/ตั้งแอดมิน/รีเซ็ตรหัส/ลบ), ประกาศทุกหน้า, ผู้ใช้ตัวอย่าง, ส่งออกข้อมูล — บัญชีทดลอง admin@fitstart.ai / admin1234 |
| `muscle.html` | สร้างกล้าม | แผนที่กล้ามเนื้อ 3D 7 ส่วน, หลักการ, คำนวณโปรตีน, **คลังท่าทั้งหมด 55 ท่า** ค้นหา/กรองได้ (`muscle.html#allex`) |
| `weight-loss.html` | ลดน้ำหนัก | หลักการ, คำนวณแคลอรี่, ท่าเผาผลาญ แยกไม่มี/มีอุปกรณ์ |
| `planner.html` | สร้างแผน | ให้ AI จัดตาราง, บันทึกแผน, โหมดนำออกกำลังกาย (วอร์มอัพ → ท่าหลัก → คูลดาวน์), **เพิ่มลงปฏิทินมือถือ** (.ics เตือนก่อน 30 นาที) |
| `bmi.html` | คำนวณ BMI | BMI, น้ำหนักที่เหมาะสม, ตารางเกณฑ์ |
| `more.html` | อื่นๆ | ตัวจับเวลาพัก, เคล็ดลับ, คลังความรู้, ความเชื่อผิดๆ, คำถามที่พบบ่อย |

ทุกหน้า: โค้ช AI (แชตมุมขวาล่าง), กดการ์ดท่าเพื่อดูรายละเอียด (ตัวละคร 3D ใหญ่ วิธีทำ เซ็ต กล้ามเนื้อ เคล็ดลับ), ปุ่ม "ข้ามไปที่เนื้อหา" สำหรับคีย์บอร์ด

## ข้อควรรู้

- ทุกหน้าโหลด `i18n → data → utils → icons → figures → layout → auth → (ไฟล์ของหน้านั้น) → coach → main` ตามลำดับนี้
- เมนูและส่วนท้ายเขียนไว้ที่เดียวใน `layout.js` แก้ทีเดียวเปลี่ยนทุกหน้า
- ลิงก์ช่วยเลือกค่าให้: `planner.html?goal=muscle`, `?level=int`, `?time=15&impact=low`, `?day=2` (เปิดการ์ดวันนั้น)
- ทุกครั้งที่แก้ css/js ให้เปลี่ยนเลข `?v=...` ในทุกหน้า เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่
- ระบบสมาชิกเป็น **แบบจำลอง**: ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ห้ามใช้รหัสผ่านจริง
- ข้อมูลในบัญชีผู้ใช้ (`fs-users` ใน localStorage): `profile`, `plans`, `log` (ประวัติฝึก + ความรู้สึก), `weights`, `water`, `protein`
- ค่าโปรตีน/แคลอรี่ของอาหารเป็นค่าประมาณ ใช้เป็นแนวทาง ไม่ใช่คำแนะนำทางการแพทย์

## โมเดล 3 มิติ

ตัวละคร 3D ใช้โมเดล 2 ตัว (โครงกระดูกแบบ Mixamo, ตัดแอนิเมชันออกและบีบขนาดแล้ว):
- `models/person.glb` — ผู้ชายเอเชียหุ่นนักกีฬา ถอดเสื้อ ใส่กางเกงขาสั้นและรองเท้าผ้าใบ สร้างด้วย [Ara 3D Gen](https://ara3dgen.com) จากข้อมูล MakeHuman (CC0, ใช้ได้ฟรีไม่ต้องให้เครดิต) ใช้ในการ์ดท่าออกกำลังกายทุกหน้า
- `models/body.glb` (X Bot จากตัวอย่างของ three.js) — หุ่นเรียบ ใช้ในแผนที่กล้ามเนื้อ หน้าสร้างกล้าม (ไฮไลต์กล้ามเป็นสีแดง)

`figures.js` โหลด three.js + `fig3d.js` เองเมื่อหน้านั้นมีตัวละคร (หน้าที่ไม่มีตัวละครจึงเบาและเร็ว) ระหว่างรอโหลดจะขึ้นวงกลมหมุน ถ้าโหลดโมเดลไม่ได้ (เช่น เปิดไฟล์จากเครื่องตรงๆ) จะใช้ตัวละครแบบเดิมแทน

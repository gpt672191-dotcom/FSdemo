# FitStart AI

เว็บเริ่มต้นออกกำลังกายด้วย AI สำหรับมือใหม่ (ไทย / อังกฤษ)
ออนไลน์: https://gpt672191-dotcom.github.io/FSdemo/ · ติดตั้งเป็นแอปบนมือถือได้ (เมนูเบราว์เซอร์ → เพิ่มลงในหน้าจอหลัก)

## หน้าเว็บ

| ไฟล์ | หน้า | มีอะไร |
|---|---|---|
| `index.html` | หน้าแรก | แนะนำเว็บ, การ์ดเลือกหมวด, แถบทักทายบอก "วันนี้" ต้องฝึกอะไร / วันพัก (ปุ่มยืดเหยียด 8 นาที) / ฝึกแล้ว (กรอบเขียวบอกนาที), รายการ "เริ่มต้นใช้งาน" 4 ขั้นสำหรับผู้ใช้ใหม่, คำแนะนำปรับระดับจากความรู้สึกหลังฝึก |
| `for-you.html` | แนะนำ | คำแนะนำจาก น้ำหนัก/ส่วนสูง/อายุ: เป้าหมาย, แคลอรี่, โปรตีน, แผน, ท่า + ตัวนับดื่มน้ำ + ตัวนับโปรตีนจากอาหารไทย |
| `profile.html` | ข้อมูลส่วนตัว | เมนูลัดติดด้านบน, ดู/แก้ไขข้อมูล, เป้าหมายสัปดาห์ (เทียบสัปดาห์ก่อน), ประวัติทั้งหมด (ลบรายการได้), บันทึกการออกกำลังกายเอง (ประมาณแคลอรี่), ความคืบหน้า (วันต่อเนื่อง ปฏิทิน 12 สัปดาห์ กราฟน้ำหนัก **น้ำหนักเป้าหมาย** (แถบคืบหน้า + เวลาโดยประมาณ) รอบเอว), เหรียญรางวัล 9 เหรียญ, ท่าโปรด + เริ่มฝึกด้วยท่าโปรด |
| `settings.html` | ตั้งค่า | ธีมสว่าง/มืด, ภาษา, ลดภาพเคลื่อนไหว, เปลี่ยนรหัสผ่าน, ดาวน์โหลด/**นำเข้า**ข้อมูล (ย้ายเครื่อง), ลบข้อมูล, ลบบัญชี |

| `weight-loss.html` | ลดน้ำหนัก | หลักการ, คำนวณแคลอรี่, ท่าเผาผลาญ แยกไม่มี/มีอุปกรณ์ |
| `planner.html` | สร้างแผน | เช็กความพร้อม (PAR-Q+), ให้ AI จัดตาราง, เพิ่มความหนักทุกสัปดาห์ (สัปดาห์ 1-4), เปลี่ยนท่าได้, บันทึกแผน, ป้าย "ทำแล้วสัปดาห์นี้" บนการ์ดวัน, โหมดนำออกกำลังกาย (วอร์มอัพ → ท่าหลัก → คูลดาวน์, ปุ่มย้อนกลับเซ็ต, จอไม่ดับระหว่างฝึก, คีย์ลัด Space/←/→/Esc), **เพิ่มลงปฏิทินมือถือ** (.ics เตือนก่อน 30 นาที) |

ทุกหน้า: โค้ช AI (แชตมุมขวาล่าง ถาม "วันนี้ต้องทำอะไร" ได้), กดการ์ดท่าเพื่อดูรายละเอียด (ตัวละคร 3D ใหญ่ วิธีทำ เซ็ต กล้ามเนื้อ ข้อผิดพลาดที่พบบ่อย ท่าง่ายลง/ยากขึ้น เคล็ดลับ), ปุ่ม "ข้ามไปที่เนื้อหา" สำหรับคีย์บอร์ด

## ข้อควรรู้

- ทุกหน้าโหลด `i18n → data → utils → icons → figures → layout → auth → (ไฟล์ของหน้านั้น) → coach → main` ตามลำดับนี้
- เมนูและส่วนท้ายเขียนไว้ที่เดียวใน `layout.js` แก้ทีเดียวเปลี่ยนทุกหน้า
- แผนเก็บ `created` (วันเริ่ม ใช้นับสัปดาห์) และ `swaps` (ท่าที่ผู้ใช้เปลี่ยน)
- ลิงก์ช่วยเลือกค่าให้: `planner.html?goal=muscle`, `?level=int`, `?time=15&impact=low`, `?day=2` (เปิดการ์ดวันนั้น)
- ทุกครั้งที่แก้ css/js ให้เปลี่ยนเลข `?v=...` ในทุกหน้า เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่
- ระบบสมาชิกเป็น **แบบจำลอง**: ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ห้ามใช้รหัสผ่านจริง
- ข้อมูลในบัญชีผู้ใช้ (`fs-users` ใน localStorage): `profile`, `plans`, `log` (ประวัติฝึก + ความรู้สึก + กิจกรรมที่บันทึกเอง), `weights`, `waist`, `goalW` (น้ำหนักเป้าหมาย), `water`, `protein`, `favs`
- การนำเข้าข้อมูลตรวจรูปแบบทุกค่า (วันที่ ตัวเลข รหัสท่า) ก่อนรวม ไฟล์ที่ถูกแก้ไขจึงใส่โค้ดอันตรายเข้ามาไม่ได้
- สีตัวอักษรผ่านเกณฑ์ความคมชัด WCAG (4.5:1) ทั้งธีมสว่างและมืด
- ค่าโปรตีน/แคลอรี่ของอาหารเป็นค่าประมาณ ใช้เป็นแนวทาง ไม่ใช่คำแนะนำทางการแพทย์

## โมเดล 3 มิติ

ตัวละคร 3D ใช้โมเดล 2 ตัว (โครงกระดูกแบบ Mixamo, ตัดแอนิเมชันออกและบีบขนาดแล้ว):
- `models/person.glb` (1.8 MB, รูปพื้นผิว WebP) — ผู้ชายเอเชียหุ่นนักกีฬา ถอดเสื้อ ใส่กางเกงขาสั้นและรองเท้าผ้าใบ สร้างด้วย [Ara 3D Gen](https://ara3dgen.com) จากข้อมูล MakeHuman (CC0, ใช้ได้ฟรีไม่ต้องให้เครดิต) ใช้ในการ์ดท่าออกกำลังกายทุกหน้า
- `models/body.glb` (X Bot จากตัวอย่างของ three.js) — หุ่นเรียบ ใช้ในแผนที่กล้ามเนื้อ หน้าสร้างกล้าม (ไฮไลต์กล้ามเป็นสีแดง)

`figures.js` โหลด three.js + `fig3d.js` เองเมื่อหน้านั้นมีตัวละคร (หน้าที่ไม่มีตัวละครจึงเบาและเร็ว) ระหว่างรอโหลดจะขึ้นวงกลมหมุน ถ้าโหลดโมเดลไม่ได้ (เช่น เปิดไฟล์จากเครื่องตรงๆ) จะใช้ตัวละครแบบเดิมแทน
